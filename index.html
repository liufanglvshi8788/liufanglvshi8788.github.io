0. 关于 WorkBuddy 的假设（请先读）

本规格按"看板系统通常具备的能力"编写（自定义字段、多视图、筛选、导出）。WorkBuddy 具体支持到什么程度，请对照第 4 节能力核对表逐项核实，再据实微调。两种情况都能落地：

  • 能力强（支持字段公式/自动化/统计）→ 月底四件套可自动生成，规格按自动方案执行；
  • 能力弱（仅看板+文本）→ 月底走"导出 Excel 手工汇总"替代方案，依然满足 15 分钟目标。

1. 总体设计

1.1 嵌入形态（二选一）

形态做法适用条件
A（推荐）复盘本身就是结构化表单：每天一条"复盘记录"，字段含考核事件WorkBuddy 复盘支持自定义字段（单选/日期/多行文本）
B复盘保持自由文本，另建一张"考核记录表"，复盘时顺手录入复盘不支持自定义字段
判断方法：在 WorkBuddy 里看"每日复盘"能否添加自定义字段或子表。能 → A；不能 → B。两种形态下数据模型相同（见 1.2），只是录入入口不同。

1.2 数据模型：一张表、四种记录类型

为避免依赖"关联/子表"能力，采用单表平铺设计：每条记录 = 一个事件 或 一条复盘文本。同一天同一成员可以有多个事件行（如当天调解成功 1 件 + 1 个失误），月底汇总时按类型归集。

主字段（所有记录共用）

字段类型选项/格式必填说明
日期日期YYYY-MM-DD✔记录日期
成员单选团队成员名单✔见第 6 节待确认清单
记录类型单选复盘 / 调解事件 / 失误事件 / 成长亮点✔一张表的四种记录
复盘正文多行文本—仅"复盘"类型今日完成事项，不参与考核计算
备注多行文本—否抵扣申请、不可抗力说明、待办

调解事件字段组（记录类型=调解事件时填写）

字段类型选项必填对应办法
案件名称文本—✔第六条
级别单选口头(30) / 简单(80) / 一般(120) / 重大(200) / 疑难(500)✔分配时定级，就高不就低（第七条）
状态单选跟进中 / 成功✔—
成功日期日期—状态=成功时按成功日期归月计奖（第八条：跨月案件成功当月计奖）
成功凭证单选调解协议书 / 确认笔录 / 支付记录等状态=成功时第九条

失误事件字段组（记录类型=失误事件时填写）

字段类型选项必填对应办法
领域单选诉讼 / 非诉调解 / 通用规范✔第十五条三张表
档次单选轻微(1分) / 一般(3分) / 重大(5分) / 底线(10分)✔四档分离（第十五、十六条）；底线=纪律红线，双人确认+取消评优+24h面谈+不抵扣+保留12月
情形编号文本如"诉讼-轻微-①"✔引用第十五条编号，保证可追溯
事实描述多行文本—✔同事项取最高档；不可抗力不记分需在此说明（第十五条）
依据说明多行文本—未列明情形时参照最相近情形并说明依据（第十五条）

成长亮点字段组（记录类型=成长亮点时填写）

字段类型选项必填对应办法
亮点类型单选调解成功 / 案件阶段成果 / 有效案源线索 / 优质普法产出✔第十二条
描述文本—✔用于月度/季度评优排名

1.3 月底输出四件套（负责人 15 分钟内完成）

#产出生成方式依据
1月度计件台账筛选"调解事件+成功"，按成功日期归月，按成员汇总金额附件四模板
2季度积分汇总表失误事件按 领域×档次 汇总；重大×2；减抵扣（每季≤5分）第十五、十六、十八条
3阈值触发提示季度累计 ≥10 提醒 / ≥18 改进计划 / ≥25 评估留用第十七条
4评优候选名单月度：当月无积分+亮点排名前二（或客户表扬）；季度：亮点≥12+无重大+未触发18分第十三、十四条

2. 功能需求明细

FR-1 每日录入（负责人操作，3-5 分钟/天）

  1. 打开看板 → 新建记录：日期（默认今天）+ 成员 + 记录类型=复盘 + 复盘正文；
  2. 有考核事件则追加事件行（调解事件 / 失误事件 / 成长亮点，按字段组填写）；
  3. 无事发生的一天：只有一条"复盘"记录，无事件行。禁止每日主观打分。

FR-2 重大失误即时动作

档次选择"底线(10分·纪律红线)"时，负责人须当天完成：

  • 记录里选"底线"，系统自动标注特殊规则（双人确认+取消当季评优+24h面谈+不抵扣+保留12月）；
  • 重大(5分)与底线区分：重大计入季度累计积分，底线单独处理、保留12个月不随季度清零；
  • 24 小时内面谈复盘（如 WorkBuddy 支持自动化提醒，设置为事件行保存后立即提醒负责人；不支持则人工执行）。

FR-3 查询视图（至少三种）

视图分组/筛选用途
成员视图按成员分组 + 当月月度评优与积分核对
日历/日期视图按日期每日复盘入口
事件视图记录类型=调解事件 / 失误事件 / 成长亮点月底汇总取数

FR-4 权限与可见性

  • 编辑权：仅团队负责人；
  • 查看权：负责人 + 成员本人（建议开放，避免月底争议）；
  • 金额/积分属团队内部管理数据，不对外。

FR-5 数据导出

月度可导出 Excel（或 CSV）用于月底台账与存档；WorkBuddy 不支持导出时，用筛选视图 + 截图/复制替代（规格按"能导出"设计）。

3. 月底 15 分钟操作手册（SOP）

  1. 筛选：事件视图 → 调解事件 + 状态=成功 + 成功日期∈本月 → 导出/复制；
  2. 对账：逐条核对成功凭证字段非空；跨月案件确认归入成功月（而不是分配月）；
  3. 计件台账：按成员汇总金额 → 填入附件四模板（或直接以导出表为台账）；
  4. 积分表：筛选失误事件 → 领域×档次汇总 → 重大×2 → 扣除备注中登记的抵扣（每季≤5分）→ 与季度累计数核对；
  5. 阈值与评优：对照第 17 条阈值输出提示；按 13/14 条生成评优候选名单；
  6. 收尾：检查本月记录完整性（无未填情形的失误行、无缺少成功日期的成功案件）。

5. 验收标准

  1. 任意抽查一个月：复盘记录汇总结果与附件四台账完全一致；
  2. 积分累计与第十五、十六、十七、十八条规则计算结果一致（四档分离、底线单独处理、抵扣上限5分、季度清零/底线保留12月）；
  3. 每日录入 ≤5 分钟；月底汇总 ≤15 分钟；
  4. 当月评优名单与 13/14 条规则一致；
  5. 重大失误（5分）记录均有面谈痕迹（记录或备注）。
